# 🐆 표범여행 (PB_foodMap) - 부산 맛집 & 가볼만한곳 명소 종합 지도 앱

부산 해운대 씨클라우드 호텔 기준 **줄 서는 부산 12대 핫플레이스 맛집**과 **대표 명소 18곳(총 30개 여행 스팟)**을 한눈에 탐색하고, 실시간 차량 도로망 경로 및 네이버 내비게이션 길안내를 제공하는 React Native (Expo) 기반 모바일/웹 여행 지도 애플리케이션입니다.

🌐 **웹 라이브 데모 (GitHub Pages)**: [https://lebass98.github.io/PB_foodMap/](https://lebass98.github.io/PB_foodMap/)

---

## 📱 주요 기능 (Key Features)

1. **[전체 (30곳)] / [🍽️ 맛집 (12곳)] / [🎡 가볼만한곳 (18곳)] 3단 듀얼 탭**
   - **맛집 BEST 12**: 융캉찌에, 광안리 진미언양불고기, 나가하마만게츠, 수변최고돼지국밥, 소문난원조조방낙지, 서희와제과, 더베이베이커리, 메트르 아티정, 해목, 해운대 가야밀면, 이재모피자(부산역점), 신발원(차이나타운)
   - **가볼만한곳 BEST 18**:
     1. **오륙도 스카이워크** (유리바닥/동해남해분기점)
     2. **이기대 해안산책로** (해안절벽 트레킹)
     3. **초량 이바구길 168계단** (피란민역사 & 무료 모노레일)
     4. **광안리 해수욕장 & 드론라이트쇼** (광안대교 뷰)
     5. **흰여울 문화마을** (부산의 산토리니 & 동굴포토존)
     6. **영도 하늘전망대** (백악기퇴적층 & 대마도조망)
     7. **국립해양박물관** (무료입장 수족관 피딩쇼)
     8. **용두산 공원 (부산타워/다이아몬드타워)** (도심전망대)
     9. **국제시장** (꽃분이네 & 구제골목)
     10. **부평 깡통시장 & 상설야시장** (야식먹거리 천국)
     11. **보수동 책방골목** (아날로그 헌책방거리)
     12. **해운대 블루라인파크 (미포정거장)** (스카이캡슐 & 해변열차)
     13. **청사포 다릿돌전망대** (슬램덩크철길뷰 & 해상스카이워크)
     14. **송정 해수욕장** (대한민국 서핑성지)
     15. **해운대 해수욕장** (호텔 바로 앞 랜드마크)
     16. **해동 용궁사** (바다 절벽 위 수상 사찰)
     17. **국립부산과학관** (탑승체험 시뮬레이터 80%)
     18. **부산 엑스더스카이** (LCT 100층 전망대)

2. **2단계 인터랙티브 상세 정보창**
   - **1단계**: 지도 핀 터치 시 오렌지/스카이블루 말풍선이 활성화되며 하단에 요약 카드 슬라이드업
   - **2단계**: 카드를 터치하면 풀스크린 **상세 정보창** 오픈 (대표 사진, 시그니처 메뉴/입장권 요금, 영상 속 타임스탬프 리뷰 및 여행 꿀팁, 운영시간/휴무일, 전화 걸기, 방문자 리뷰)

3. **실시간 차량 주행 경로선 & 네이버 내비 딥링크**
   - 실제 도로망(OSRM Routing API)을 기반으로 한 주행선(Polyline) 렌더링
   - `[네이버 내비로 안내 시작 🧭]` 버튼 터치 시 네이버 지도 앱 실시간 음성 내비게이션 즉시 실행

4. **사용자 경험 최적화**
   - **깜박임 0%**: 상호명/명소 클릭 시 지도 새로고침 없이 0.4초간 부드러운 스무스 팬(`panTo`)
   - **줌 배율 유지**: 지도를 자유롭게 확대/축소한 상태에서 마커를 클릭해도 줌 크기 그대로 보존
   - **세로형 줌 컨트롤러**: 우측 상단 내 위치 버튼 바로 아래 `[ + ]` / `[ - ]` 줌 버튼 탑재
   - **Pretendard 전역 폰트 & 라이트 모드** 기본 적용

## 🛠️ 기술 스택 (Tech Stack)

- **Framework**: React Native (Expo SDK 54)
- **Language**: TypeScript
- **Styling**: Tailwind CSS (NativeWind v4)
- **Map Engine**: Naver Maps JavaScript API v3 / Leaflet Map Engine
- **Icons**: Lucide React Native
- **Typography**: Pretendard Font Family (Regular, Medium, SemiBold, Bold)
- **Location & Routing**: `expo-location`, OSRM Driving Route API
- **CI/CD & Hosting**: GitHub Actions (`deploy-pages.yml`) & GitHub Pages

## 🚀 시작하기 (Getting Started)

### 1. 패키지 설치
```bash
npm install
```

### 2. Expo 로컬 개발 서버 실행
```bash
npx expo start -c
```

### 3. 웹 정적 빌드 및 배포
```bash
npx expo export --platform web
```
- `main` 브랜치에 코드를 푸시하면 GitHub Actions를 통해 GitHub Pages에 자동 배포됩니다.
