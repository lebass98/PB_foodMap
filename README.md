# 🐆 표범맛집 (PB_foodMap) - 부산 맛집 지도 앱

부산 해운대 씨클라우드 호텔 기준 **줄 서는 부산 12대 핫플레이스 맛집**을 한눈에 탐색하고, 실시간 차량 도로망 경로 및 네이버 내비게이션 길안내를 제공하는 React Native (Expo) 기반 모바일/웹 맛집 지도 애플리케이션입니다.

---

## 📱 주요 기능 (Key Features)

1. **부산 12대 대표 맛집 지도 & 리스트 뷰**
   - 해운대/광안리/초량 차이나타운 등 미쉐린 빕구르망, 블루리본, 성시경 '먹을텐데', 백종원 3대천왕 선정 맛집 12곳 완벽 수록
   - 상단 헤더의 **지도(Map) / 목록(List)** 원터치 전환

2. **2단계 인터랙티브 상세 정보창**
   - **1단계**: 지도 상호명(말풍선 핀) 클릭 시 해당 핀이 주황색으로 활성화(`scale 1.2x`)되며 하단에 요약 카드 슬라이드업
   - **2단계**: 요약 카드를 터치하면 풀스크린 **가게 상세 정보창** 오픈 (대표 사진, 시그니처 메뉴 및 가격표, 영상 속 타임스탬프 상세 리뷰, 영업시간/브레이크타임/휴무일, 전화 걸기, 방문자 리뷰)

3. **실시간 차량 주행 경로선 & 네이버 내비 딥링크**
   - 실제 도로망(OSRM Routing API)을 기반으로 한 주행선(Polyline) 렌더링
   - `[네이버 내비로 안내 시작 🧭]` 버튼 터치 시 네이버 지도 앱 실시간 음성 내비게이션 즉시 실행

4. **사용자 경험 최적화**
   - **깜박임 0%**: 상호명 클릭 및 이동 시 지도 새로고침 없이 0.4초간 부드러운 스무스 팬(`panTo`)
   - **줌 배율 유지**: 지도를 자유롭게 확대/축소한 상태에서 상호명을 클릭해도 줌 크기 그대로 보존
   - **세로형 줌 컨트롤러**: 우측 상단 내 위치 버튼 바로 아래 `[ + ]` / `[ - ]` 줌 버튼 탑재
   - **Pretendard 전역 폰트 & 라이트 모드** 기본 적용

---

## 🛠️ 기술 스택 (Tech Stack)

- **Framework**: React Native (Expo SDK 54)
- **Language**: TypeScript
- **Styling**: Tailwind CSS (NativeWind v4)
- **Map Engine**: Naver Maps JavaScript API v3 / Leaflet Map Engine
- **Icons**: Lucide React Native
- **Typography**: Pretendard Font Family (Regular, Medium, SemiBold, Bold)
- **Location & Routing**: `expo-location`, OSRM Driving Route API

---

## 🚀 시작하기 (Getting Started)

### 1. 패키지 설치
```bash
npm install
```

### 2. Expo 로컬 개발 서버 실행
```bash
npx expo start -c
```
- 터미널에 나타나는 QR 코드를 스마트폰 **Expo Go** 앱으로 스캔하거나, `w` 키를 눌러 웹 브라우저에서 실행할 수 있습니다.
