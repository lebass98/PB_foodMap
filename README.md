# 🐆 표범여행 (PB_foodMap) - 부산 맛집 & 가볼만한곳 명소 지도 앱

부산 해운대 씨클라우드 호텔 기준 **줄 서는 부산 12대 핫플레이스 맛집**과 **대표 명소 8곳(총 20곳)**을 한눈에 탐색하고, 실시간 차량 도로망 경로 및 네이버 내비게이션 길안내를 제공하는 React Native (Expo) 기반 모바일/웹 여행 지도 애플리케이션입니다.

🌐 **웹 라이브 데모 (GitHub Pages)**: [https://lebass98.github.io/PB_foodMap/](https://lebass98.github.io/PB_foodMap/)

---

## 📱 주요 기능 (Key Features)

1. **[전체] / [🍽️ 맛집 BEST 12] / [🎡 가볼만한곳 BEST 8] 듀얼 탭**
   - **맛집 12곳**: 융캉찌에, 광안리 진미언양불고기, 나가하마만게츠, 수변최고돼지국밥, 소문난원조조방낙지, 서희와제과, 더베이베이커리, 메트르 아티정, 해목, 해운대 가야밀면, 이재모피자, 신발원
   - **가볼만한곳 8곳**: 해운대 블루라인파크(스카이캡슐), 부산 엑스더스카이(100층 전망대), 동백섬 & 누리마루, 더베이101(야경), 광안리 해수욕장 & 드론쇼, 해동용궁사, 롯데월드 어드벤처 & 루지, 흰여울문화마을
   - 상단 원터치 탭으로 맛집과 명소를 손쉽게 넘나들며 탐색

2. **2단계 인터랙티브 상세 정보창**
   - **1단계**: 지도 핀 터치 시 오렌지/스카이블루 말풍선이 하이라이트(`scale 1.2x`)되며 하단에 요약 카드 슬라이드업
   - **2단계**: 카드를 누르면 풀스크린 **상세 정보창** 오픈 (대표 사진, 시그니처 메뉴/입장권 요금, 영상 속 타임스탬프 리뷰 및 여행 꿀팁, 운영시간/휴무일, 전화 걸기, 방문자 리뷰)

3. **실시간 차량 주행 경로선 & 네이버 내비 딥링크**
   - 실제 도로망(OSRM Routing API)을 기반으로 한 주행선(Polyline) 렌더링
   - `[네이버 내비로 안내 시작 🧭]` 버튼 터치 시 네이버 지도 앱 실시간 음성 내비게이션 즉시 실행

4. **사용자 경험 최적화**
   - **깜박임 0%**: 상호명/명소 클릭 시 지도 새로고침 없이 0.4초간 부드러운 스무스 팬(`panTo`)
   - **줌 배율 유지**: 지도를 자유롭게 확대/축소한 상태에서 마커를 클릭해도 줌 크기 그대로 보존
   - **세로형 줌 컨트롤러**: 우측 상단 내 위치 버튼 바로 아래 `[ + ]` / `[ - ]` 줌 버튼 탑재
   - **Pretendard 전역 폰트 & 라이트 모드** 기본 적용

## 🛠️ 기술 스택 (Tech Stack)

- **Framework**: React Native (Expo SDK 54)
- **Language**: TypeScript
- **Styling**: Tailwind CSS (NativeWind v4)
- **Map Engine**: Naver Maps JavaScript API v3 / Leaflet Map Engine
- **Icons**: Lucide React Native
- **Typography**: Pretendard Font Family (Regular, Medium, SemiBold, Bold)
- **Location & Routing**: `expo-location`, OSRM Driving Route API
- **CI/CD & Hosting**: GitHub Actions (`deploy-pages.yml`) & GitHub Pages

## 🚀 시작하기 (Getting Started)

### 1. 패키지 설치
```bash
npm install
```

### 2. Expo 로컬 개발 서버 실행
```bash
npx expo start -c
```
- 터미널에 나타나는 QR 코드를 스마트폰 **Expo Go** 앱으로 스캔하거나, `w` 키를 눌러 웹 브라우저에서 실행할 수 있습니다.

### 3. 웹 정적 빌드 및 배포
```bash
npx expo export --platform web
```
- `main` 브랜치에 코드를 푸시하면 GitHub Actions를 통해 GitHub Pages에 자동 배포됩니다.
