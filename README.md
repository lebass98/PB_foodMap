# 🧭 Glory Travel (PB_foodMap) - 맛집 & 가볼만한곳 명소 종합 여행 지도 앱

시흥 은행동 출발부터 부산 해운대 씨클라우드 호텔까지 **고속도로 경유 맛집 3곳 + 줄 서는 부산 12대 핫플레이스 맛집(총 15곳 맛집)**과 **대표 명소 32곳(총 47개 여행 스팟)**을 한눈에 탐색하고, 앱 내부 자체 지도에서 실제 도로 주행 경로선과 소요시간을 바로 확인할 수 있는 React Native (Expo) 기반 모바일/웹 여행 지도 애플리케이션입니다.

🌐 **웹 라이브 데모 (GitHub Pages)**: [https://lebass98.github.io/PB_foodMap/](https://lebass98.github.io/PB_foodMap/)

---

## 📱 주요 기능 (Key Features)

1. **[전체 (47곳)] / [🍽️ 맛집 (15곳)] / [🎡 가볼만한곳 (32곳)] 3단 듀얼 탭**
   - **맛집 BEST 15**: 
     - **고속도로/경유 맛집 3곳**: 새재할매집 (문경새재IC 약돌돼지 석쇠구이), 교리김밥 본점 (경주IC 전국 3대 계란지단김밥), 금천 아지매 보리밥 (청도/밀양IC 시골 밥상)
     - **부산 12대 미식 핫플**: 융캉찌에, 진미언양불고기, 나가하마만게츠, 수변최고돼지국밥, 조방낙지, 서희와제과, 더베이베이커리, 메트르 아티정, 해목, 가야밀면, 이재모피자(부산역점), 신발원(차이나타운)
   - **가볼만한곳 BEST 32 (중복 0건 전수 정돈)**:
     1. **부산 엑스더스카이 (BUSAN X the SKY)** (한국관광 100선 100층 전망대 & 쇼킹브릿지)

     3. **기장 대형 오션뷰 카페 BEST** (이흥용 명장 칠암사계 소금빵 & 웨이브온 & 코랄라니)

     5. **부산항대교 (2층 시티투어버스)** (360도 나선형 롤러코스터 램프 & 무지개 야경)

     7. **송도 해상케이블카 & 송도용궁구름다리** (86m 상공 케이블카 & 127m 해상 현수보행교)
     8. **동생말 전망대** (해운대 스카이라인 조망)
     9. **이기대 수변공원 (어울마당)** (해안절벽 트레킹 & 바다 라면/맥주)
     10. **오륙도 스카이워크 & 해맞이공원** (35m 해안절벽 유리바닥 & 수선화/유채꽃)
     11. **황령산 봉수대** (부산 1등 360도 파노라마 야경 & 벚꽃길)

     13. **해동 용궁사** (바다 절벽 위 수상 사찰 & 동전 던지기 소원 성취)

     15. **태종대 유원지 (다누비열차·태종사)** (영도등대 & 여름 수국)

     31. **보수동 책방골목** (전국 유일 아날로그 헌책방거리)
     32. **국립부산과학관** (탑승체험 시뮬레이터 80%)

2. **앱 내부 자체 지도 경로선 & 소요시간 대시보드**
   - 외부 내비 앱으로 이탈하지 않고, 앱 내 자체 지도 위에서 **실제 도로망 주행선(Polyline)**을 부드럽게 렌더링.
   - 상단 대시보드에 **"씨클라우드 호텔 ➔ [목적지] : 차량 약 몇 분 (몇 km) 소요"**를 직관적으로 표시.

3. **2단계 인터랙티브 상세 정보창**
   - **1단계**: 지도 핀 터치 시 오렌지/스카이블루 말풍선이 활성화되며 하단에 요약 카드 슬라이드업
   - **2단계**: 카드를 터치하면 풀스크린 **상세 정보창** 오픈 (대표 사진, 시그니처 메뉴/입장권 요금, 영상 속 타임스탬프 리뷰 및 여행 꿀팁, 운영시간/휴무일, 전화 걸기, 방문자 리뷰)

4. **사용자 경험 최적화**
   - **깜박임 0%**: 상호명/명소 클릭 시 지도 새로고침 없이 0.4초간 부드러운 스무스 팬(`panTo`)
   - **줌 배율 유지**: 지도를 자유롭게 확대/축소한 상태에서 마커를 클릭해도 줌 크기 그대로 보존
   - **세로형 줌 컨트롤러**: 우측 상단 내 위치 버튼 바로 아래 `[ + ]` / `[ - ]` 줌 버튼 탑재
   - **Pretendard 전역 폰트 & 라이트 모드** 기본 적용

## 🛠️ 기술 스택 (Tech Stack)

- **Framework**: React Native (Expo SDK 54)
- **Language**: TypeScript
- **Styling**: Tailwind CSS (NativeWind v4)
- **Map Engine**: Naver Maps JavaScript API v3 / Leaflet Map Engine
- **Icons**: Lucide React Native
- **Typography**: Pretendard Font Family (Regular, Medium, SemiBold, Bold)
- **Location & Routing**: `expo-location`, OSRM Driving Route API
- **CI/CD & Hosting**: GitHub Actions (`deploy-pages.yml`) & GitHub Pages

## 🚀 시작하기 (Getting Started)

### 1. 패키지 설치
```bash
npm install
```

### 2. Expo 로컬 개발 서버 실행
```bash
npx expo start -c
```

### 3. 웹 정적 빌드 및 배포
```bash
npx expo export --platform web
```
- `main` 브랜치에 코드를 푸시하면 GitHub Actions를 통해 GitHub Pages에 자동 배포됩니다.
